Privacy policy

Last updated: November 18, 2026

The Leonida Clips uploader is a private tool used only by the owner of the Leonida Clips YouTube channel.

What it accesses

With the owner's permission, it uses the YouTube Data API to upload videos to the owner's own channel and to read view counts of those videos. It uses no other Google data.

What it stores

It stores a list of the videos it has posted (video IDs, titles and public stats). It does not collect, sell or share personal data about anyone.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.
